# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately through a
[GitHub private security advisory](https://github.com/jame17291-sys/jakh.net/security/advisories/new).
Do not open a public issue or publish exploit details before a fix is available.

Include the affected URL or component, impact, reproduction steps, and any
supporting request/response details with secrets and personal data removed.
Reports should avoid denial-of-service testing, automated high-volume scans,
accessing another person's data, or changing production data.

The current production release on the default branch is supported. Historical
commits, local development environments, and retired infrastructure are not
supported unless they still affect production.

We will acknowledge actionable reports through the private advisory, coordinate
validation and remediation there, and agree on disclosure timing after users
are protected.

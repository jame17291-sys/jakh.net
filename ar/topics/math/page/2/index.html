◷ المراجعة التحريرية للحقائق معلّقة

افتح البطاقة في الاختبار التفاعلي ←
35ثلاثة رجال دفعوا $10 لكل منهم ($30). المدير رد $5 عبر خادم أخذ $2 وأعطى $1 لكل رجل. دفع كل رجل $9 (المجموع $27). $27 + $2 = $29. أين الدولار المفقود؟

الإجابة

لا يوجد دولار مفقود. دفع الرجال $27 إجمالاً ($25 للغرفة + $2 إكرامية). جمع الـ$2 مع الـ$27 هو الخدعة — الـ$2 موجودة بالفعل داخل الـ$27 وليست خارجها. الحساب الصحيح: $30 مدفوعة − $3 مُستردة = $27 أُنفقت، موزعة: $25 (الفندق) + $2 (الخادم).

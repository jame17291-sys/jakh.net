Which question should we ask?

What we’re practising

Design a discriminating question.

Before you begin

Draw a large red ball and a small red ball.

Let’s try it

  1. Draw a large red ball and a small red ball.
  2. Ask: To find the large ball, is “Is it red?” enough? What should we ask instead?
  3. Choose or draw an answer. Explain it using the clues; check the explanation together after trying.

Talk about it

Draw a large red ball and a small red ball. To find the large ball, is “Is it red?” enough? What should we ask instead?

A little hint
  • Both choices are red.
Answer & what to notice

No. Ask “Is it the large ball?”

Colour does not separate these choices, but size does.

Make it easier

Say each ball's size aloud.

Take it further

Add a large blue ball and find two questions that identify each one.

Away from the screen

On another day, draw your own version of this challenge and explain which details must stay the same for the answer to work.

What you’ll need

  • Paper
  • Pencil or crayons

Use what you have

An adult can describe the scene aloud and accept a spoken or pointed answer. No printer is needed.

Grown-up note

An adult reads and draws with the child using age-appropriate drawing tools. Explore the situation in pictures.

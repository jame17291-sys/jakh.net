Ages 7–8 · Logic & problem-solving

A machine that swaps

Execute a two-step algorithm.

10 minIndependent readerGrown-up nearby

What we’re practising

Execute a two-step algorithm.

Before you begin

Write A B C from left to right. The machine swaps the first two, then the last two.

Let’s try it

  1. Write A B C from left to right. The machine swaps the first two, then the last two.
  2. Ask: What order comes out after both swaps?
  3. Choose or draw an answer. Explain it using the clues; check the explanation together after trying.

Talk about it

Write A B C from left to right. The machine swaps the first two, then the last two. What order comes out after both swaps?

A little hint
  • Record the intermediate row.
Answer & what to notice

B C A, from left to right.

A B C becomes B A C, then B C A.

Make it easier

Draw an arrow between the two positions being swapped.

Take it further

Swap the last two first, then the first two; compare results.

Away from the screen

On another day, draw your own version of this challenge and explain which details must stay the same for the answer to work.

What you’ll need

  • Paper
  • Pencil or crayons

Use what you have

An adult can describe the scene aloud and accept a spoken or pointed answer. No printer is needed.

Grown-up note

Explore the situation on paper with suitable drawing tools. Ask an adult before trying a real-world investigation.

Crack the four-digit order

Arrange four different digits using three ordering clues.

15 minIndependent readerTry independently

What we’re practising

Use adjacency and ordering constraints to eliminate permutations.

Before you begin

The code uses 1, 2, 3 and 4 exactly once, read from left to right.

Let’s try it

  1. Write the clues: 1 is immediately before 3; 4 is before 2; 2 is not last.
  2. Treat 1 and 3 as an ordered block and try possible placements.
  3. Reject any order that breaks one clue.
  4. Check the remaining code against all three clues.

Talk about it

How does treating 13 as a block reduce the search?

A little hint
  • Arrange the three pieces 13, 4 and 2; then apply the other two clues.
Answer & what to notice

The code is 4213, read left to right: four, two, one, three.

With 4 before 2, the possible block orders are 13–4–2, 4–13–2 and 4–2–13; only the last avoids ending in 2.

Make it easier

Provide the three possible block orders to compare.

Take it further

Remove one clue and count how many codes become possible.

Away from the screen

Write an ordering puzzle with four animal names and verify its solution count.

What you’ll need

  • Paper
  • Pencil

Use what you have

Use large handwritten cards for digits 1, 2, 3 and 4.

Grown-up note

Use an invented puzzle code, never a real password or device PIN.

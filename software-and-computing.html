💻 Software & Computing Easy Computer Science

What does CPU stand for and what does it do?

◷ Editorial fact review pending

Central Processing Unit — the primary component that executes instructions and performs calculations in a computer.

💻 Software & Computing Easy Computer Science

What is the difference between RAM and ROM?

◷ Editorial fact review pending

RAM (Random Access Memory) is volatile — it stores data temporarily while the computer is running. ROM (Read-Only Memory) is non-volatile — it stores permanent instructions (like firmware) that persist even when powered off.

💻 Software & Computing Easy Computer Science

What is binary and why do computers use it?

◷ Editorial fact review pending

Binary is a base-2 number system using only 0 and 1. Computers use it because transistors have two states — on (1) and off (0) — making binary natural for digital circuits.

💻 Software & Computing Easy Algorithms & Data Structures

What is an array in programming?

◷ Editorial fact review pending

A data structure that stores elements of the same type in contiguous memory locations, accessible by an index starting from 0.

💻 Software & Computing Easy Systems & Networking

What is an IP address?

◷ Editorial fact review pending

A unique numerical label assigned to each device on a network, used to identify and communicate with it. IPv4 uses 32-bit addresses (e.g., 192.168.1.1); IPv6 uses 128-bit addresses.

💻 Software & Computing Easy Software Engineering

What is the difference between a compiler and an interpreter?

◷ Editorial fact review pending

A compiler translates the entire source code into machine code before execution. An interpreter translates and executes code line by line at runtime.

💻 Software & Computing Easy Computer Science

What is an operating system (OS)?

◷ Editorial fact review pending

Software that manages hardware resources and provides services for application programs. Examples: Windows, macOS, Linux.

💻 Software & Computing Easy Algorithms & Data Structures

What is a linked list and how does it differ from an array?

◷ Editorial fact review pending

A linked list is a data structure where each element (node) stores data and a pointer to the next node. Unlike arrays, nodes are not contiguous in memory, making insertions/deletions fast (O(1) if pointer is known) but random access slow (O(n)).

💻 Software & Computing Easy Systems & Networking

What does HTTP stand for and what is it used for?

◷ Editorial fact review pending

HyperText Transfer Protocol — the foundation of data communication on the World Wide Web, used to transfer web pages and other resources between a browser and a server.

💻 Software & Computing Easy Software Engineering

What is version control and why is Git widely used?

◷ Editorial fact review pending

Version control tracks changes to code over time, allowing teams to collaborate, roll back errors, and maintain history. Git is a distributed VCS — every developer has a full copy of the repository, enabling offline work and fast branching.

💻 Software & Computing Easy Computer Science

What is an algorithm?

◷ Editorial fact review pending

A finite, ordered set of well-defined instructions that solves a problem or accomplishes a task.

💻 Software & Computing Easy Systems & Networking

What is the difference between a process and a thread?

◷ Editorial fact review pending

A process is an independent program instance with its own memory space. Threads are lighter-weight units of execution within a process, sharing the same memory — enabling concurrency with less overhead.

💻 Software & Computing Easy Software Engineering

What is object-oriented programming (OOP)?

◷ Editorial fact review pending

A programming paradigm that organises code around 'objects' — entities that bundle data (attributes) and behaviour (methods). Core principles: encapsulation, inheritance, polymorphism, and abstraction.

💻 Software & Computing Easy Algorithms & Data Structures

What is a stack data structure and what is its primary operation order?

◷ Editorial fact review pending

A stack is a LIFO (Last In, First Out) data structure — the most recently added element is the first removed. Operations: push (add to top), pop (remove from top).

💻 Software & Computing Medium Algorithms & Data Structures

What is Big O notation and what does O(n log n) mean?

◷ Editorial fact review pending

Big O describes the worst-case time or space complexity of an algorithm as input size (n) grows. O(n log n) means execution time grows proportionally to n multiplied by the logarithm of n — typical of efficient comparison-based sorting algorithms like merge sort and heapsort.

💻 Software & Computing Medium Systems & Networking

What is the OSI model and how many layers does it have?

◷ Editorial fact review pending

The Open Systems Interconnection model is a 7-layer conceptual framework for network communication: Physical, Data Link, Network, Transport, Session, Presentation, Application. Each layer handles specific functions and communicates with adjacent layers.

💻 Software & Computing Medium Software Engineering

What is the difference between SQL and NoSQL databases?

◷ Editorial fact review pending

SQL (relational) databases store structured data in tables with fixed schemas and use SQL for queries — strong consistency, ACID transactions (e.g., PostgreSQL, MySQL). NoSQL databases use flexible schemas (document, key-value, graph, column) — better horizontal scalability and performance for unstructured data (e.g., MongoDB, Redis, Cassandra).

💻 Software & Computing Medium Algorithms & Data Structures

What is a hash table and what is its average time complexity for lookups?

◷ Editorial fact review pending

A hash table stores key-value pairs by computing a hash of the key to determine storage location. Average O(1) for insertions, lookups, and deletions. Worst-case O(n) with many collisions.

💻 Software & Computing Medium Systems & Networking

What is DNS and how does it work?

◷ Editorial fact review pending

The Domain Name System translates human-readable domain names (e.g., example.com) into IP addresses. When you request a URL, a DNS resolver queries a hierarchy of servers (root → TLD → authoritative) to find the corresponding IP.

💻 Software & Computing Medium Software Engineering

What is the SOLID principle in object-oriented design?

◷ Editorial fact review pending

Five design principles: Single Responsibility (one reason to change), Open/Closed (open for extension, closed for modification), Liskov Substitution (subclasses substitutable for parent), Interface Segregation (specific interfaces), Dependency Inversion (depend on abstractions, not concretions).

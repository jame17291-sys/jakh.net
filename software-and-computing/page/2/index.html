21What is recursion and what is a base case?

Answer

Recursion is when a function calls itself to solve a smaller instance of the same problem. A base case is the condition that terminates the recursion — without it, the function would call itself infinitely and cause a stack overflow.

22Explain Dijkstra's algorithm and its time complexity.

Answer

Dijkstra's algorithm finds the shortest path from a source node to all others in a weighted graph with non-negative edges. It greedily picks the unvisited node with the smallest known distance, relaxes its neighbours, and repeats. With a binary heap: O((V + E) log V), where V = vertices and E = edges.

23What is a race condition and how can it be prevented?

Answer

A race condition occurs when the behaviour of a program depends on the relative timing of threads accessing shared data — leading to unpredictable results. Prevention: synchronisation primitives (mutexes, semaphores, monitors), atomic operations, or lock-free data structures.

24What is the CAP theorem in distributed systems?

Answer

CAP theorem (Brewer) states a distributed system can guarantee at most two of three properties simultaneously: Consistency (every read receives the most recent write), Availability (every request receives a response), and Partition Tolerance (system continues despite network partitions).

25What is the difference between dynamic programming and greedy algorithms?

Answer

Dynamic programming solves problems by breaking them into overlapping subproblems and storing results (memoisation/tabulation) — optimal solution guaranteed. Greedy algorithms make locally optimal choices at each step without reconsidering — faster but not always globally optimal (e.g., Dijkstra is greedy and optimal; fractional knapsack is greedy; 0/1 knapsack requires DP).

26What is virtual memory and how does paging work?

Answer

Virtual memory gives each process the illusion of a large, private address space even if physical RAM is limited. Paging divides virtual addresses into fixed-size pages mapped to physical frames by a page table. When a page is not in RAM (page fault), the OS loads it from disk.

27What is test-driven development (TDD) and what is the 'Red-Green-Refactor' cycle?

Answer

TDD is a development approach where tests are written before production code. Cycle: Red (write a failing test), Green (write minimal code to pass the test), Refactor (clean up code while keeping tests green). Benefits: better design, coverage, and fewer regressions.

28What is the halting problem and what did Turing prove about it?

Answer

The halting problem asks whether a general algorithm can determine if any given program will eventually halt or run forever. Turing proved (1936) this is undecidable — no such general algorithm can exist — by demonstrating a contradiction (if it could, you could construct a program that halts iff it doesn't).

29What is a balanced binary search tree (BST) and why is balance important?

Answer

A BST where the heights of subtrees are kept close (e.g., AVL tree: height difference ≤ 1; Red-Black tree: more relaxed). Balance ensures search, insertion, and deletion remain O(log n) in the worst case. An unbalanced BST can degrade to O(n) — a linked list.

30What is the difference between TCP and UDP?

Answer

TCP (Transmission Control Protocol) is connection-oriented with guaranteed delivery, ordering, and error checking — higher overhead (e.g., web, email). UDP (User Datagram Protocol) is connectionless with no delivery guarantees — lower latency, used for real-time applications (e.g., video streaming, DNS, gaming).

31What is microservices architecture and how does it differ from monolithic architecture?

Answer

Monolithic: a single deployable unit containing all functionality — simple to develop initially but hard to scale and modify. Microservices: functionality split into small, independently deployable services communicating via APIs — better scalability and team autonomy, but increased operational complexity (networking, distributed tracing, eventual consistency).

32What is garbage collection and what are the tradeoffs between manual memory management and GC?

Answer

Garbage collection automatically reclaims memory no longer referenced — preventing memory leaks at the cost of runtime pauses and overhead (e.g., Java, Python, Go). Manual management (C, C++) gives precise control and no GC pauses but risks memory leaks, use-after-free, and double-free bugs.

33What is the difference between depth-first search (DFS) and breadth-first search (BFS)?

Answer

DFS explores as far as possible along each branch before backtracking — uses a stack (or recursion); good for cycle detection, topological sort. BFS explores all neighbours at the current depth before going deeper — uses a queue; good for shortest path in unweighted graphs.

34What is a deadlock in operating systems and what are the four Coffman conditions?

Answer

A deadlock is a state where two or more processes are permanently blocked, each waiting for a resource held by another. Coffman conditions (all four must hold): (1) Mutual Exclusion, (2) Hold and Wait, (3) No Preemption, (4) Circular Wait.

35What is eventual consistency in distributed databases?

Answer

A consistency model where, given no new updates, all replicas of data will eventually converge to the same value — but temporary inconsistencies are allowed between replicas. Used by highly available systems (Cassandra, DynamoDB). Contrasts with strong consistency (all reads reflect the latest write immediately).

36What is the difference between P, NP, and NP-complete problems?

Answer

P: problems solvable in polynomial time. NP: problems where a proposed solution can be verified in polynomial time (but may not be solvable that fast). NP-complete: the hardest NP problems — every NP problem reduces to them in polynomial time. Whether P = NP is the most famous unsolved problem in computer science.

37What is HTTPS and how does TLS protect web traffic?

Answer

HTTPS is HTTP over TLS (Transport Layer Security). TLS provides encryption (prevents eavesdropping), authentication (server certificate verifies identity), and integrity (prevents tampering). The TLS handshake negotiates cipher suites and exchanges session keys using asymmetric cryptography before switching to symmetric encryption.

38What is a design pattern? Name and explain three common ones.

Answer

Reusable solutions to common software design problems (GoF book). Three examples: Singleton (ensure only one instance of a class exists), Observer (subject notifies a list of observers on state change — event-driven systems), Factory Method (delegate object creation to subclasses, hiding instantiation logic).

39What is Byzantine fault tolerance and why is it important in distributed systems?

Answer

Byzantine fault tolerance (Lamport, 1982) is the ability of a system to continue operating even if some nodes fail in arbitrary ways — including sending conflicting information. Standard fault tolerance handles crash failures; Byzantine tolerance handles malicious or corrupted nodes. It requires at least 3f+1 nodes to tolerate f faulty ones. Critical for blockchain consensus (PBFT, Tendermint).

40What is the Raft consensus algorithm and what problem does it solve?

Answer

Raft (Ongaro & Ousterhout, 2014) is a consensus algorithm for distributed systems that ensures multiple nodes agree on a sequence of values even in the presence of failures. It decomposes consensus into leader election, log replication, and safety. Designed as a more understandable alternative to Paxos — used in etcd, CockroachDB.

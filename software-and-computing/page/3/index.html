41What is a cache coherence protocol and why does it matter for multi-core processors?

Answer

In multi-core CPUs, each core has its own cache. Cache coherence protocols (e.g., MESI — Modified, Exclusive, Shared, Invalid) ensure all caches present a consistent view of memory. Without coherence, one core might read a stale value written by another. The protocol uses bus snooping or directory-based mechanisms to track cache line states.

42What is the difference between a Turing machine and a finite automaton, and what classes of languages do they recognise?

Answer

A finite automaton has a fixed number of states and no external memory — recognises regular languages (the lowest class in the Chomsky hierarchy). A Turing machine has a potentially infinite tape, can read/write/move in both directions — recognises Turing-recognisable (recursively enumerable) languages. Between them: pushdown automata (context-free languages) and linear-bounded automata (context-sensitive).

43What is event sourcing and how does it differ from traditional CRUD?

Answer

In traditional CRUD, the database stores current state. In event sourcing, only immutable events (facts about what happened) are stored; current state is derived by replaying the event log. Benefits: full audit trail, temporal queries, easy projection rebuilding. Tradeoffs: increased storage, more complex querying, event schema evolution challenges.

44What is a skip list and what are its time complexity guarantees?

Answer

A skip list is a probabilistic data structure with multiple linked layers, each a subset of the layer below, allowing O(log n) expected search, insertion, and deletion. It achieves the same performance as balanced BSTs without complex rotations. Used in Redis sorted sets and LevelDB.

45What is eBPF (extended Berkeley Packet Filter) and what are its modern uses?

Answer

eBPF allows sandboxed programs to run in the Linux kernel without modifying kernel source or loading modules. Modern uses: high-performance networking (bypassing kernel stack — XDP), observability (tracing system calls, latency without overhead — Cilium, BPF Compiler Collection), security (runtime threat detection), and load balancing.

46What is the difference between optimistic and pessimistic concurrency control in databases?

Answer

Pessimistic concurrency: acquires locks before reading/writing, preventing conflicts — safer but reduces throughput (deadlock risk). Optimistic concurrency: no locks; transactions proceed and only check for conflicts at commit time; if a conflict is detected, the transaction is rolled back and retried. Better for low-contention workloads.

47What is type theory and how does the Curry-Howard correspondence connect it to logic?

Answer

Type theory studies formal systems that classify values by type. The Curry-Howard correspondence states that types are propositions and programs are proofs — an inhabited type corresponds to a provable proposition. This deep connection underpins dependently typed languages (Coq, Agda, Lean) used for program verification.

48What is amortised analysis and how does it apply to a dynamic array's resize operation?

Answer

Amortised analysis computes the average cost per operation over a sequence, even if some individual operations are expensive. A dynamic array doubles its capacity when full: most appends are O(1), but occasional resize is O(n). Amortised cost per append is still O(1) because each element is moved at most a constant number of times across all doublings.

49What is the LMAX Disruptor and what architectural choices make it achieve high throughput?

Answer

The LMAX Disruptor is a high-performance inter-thread messaging library using a ring buffer with no locks. Key techniques: pre-allocated fixed-size ring buffer (no GC pressure), CPU cache-line padding to avoid false sharing, memory barriers instead of locks, and busy-spin waiting for lowest latency. It achieves millions of events per second within a JVM.

50What is quantum computing and what types of problems does it solve faster than classical computers?

Answer

Quantum computers use qubits (superposition of 0 and 1) and entanglement to perform massively parallel computations. Proven speedups: Shor's algorithm (factoring large numbers exponentially faster — breaks RSA), Grover's algorithm (unstructured search in O(√n) vs classical O(n)). Practical quantum advantage for broader problems is still being researched.
